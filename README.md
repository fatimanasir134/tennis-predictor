# 🎾 ATP Tennis Match Predictor

A machine learning web application that predicts the win probability of a match between two ATP players — built with Python, scikit-learn, and Streamlit.

> **No betting odds used.** The model relies solely on ATP rankings, points, and match context.

---

## Features

- **Match Predictor** — select any two ATP players, configure surface/round/series, and get instant win probabilities
- **Confidence Gauge** — visual arc indicator showing how certain the model is (green / amber / red)
- **Head-to-Head History** — full H2H record, timeline chart, surface breakdown, and last 5 meetings
- **Surface Win Rates** — per-player win rate bar charts and W/L tables across all surfaces
- **Match History Explorer** — searchable/filterable table of all 69,000+ historical ATP matches (2000–2026)
- **Model Performance Dashboard** — hold-out accuracy, match count, and model configuration summary
- **Feature Importance Charts** — built-in impurity importance, permutation importance, and optional SHAP plots

## Getting Started

### 1. Clone the repo

```bash
git clone https://github.com/YOUR_USERNAME/tennis-predictor.git
cd tennis-predictor
```

### 2. Create a virtual environment and install dependencies

```bash
python -m venv .venv
# Windows
.venv\Scripts\activate
# macOS / Linux
source .venv/bin/activate

pip install -r requirements.txt
```

### 3. Run the data pipeline (one-time setup)

```bash
python src/01_data_preparation.py
python src/02_feature_engineering.py
python src/03_model_building.py
python src/04_model_interpretation.py
python src/05_live_prediction.py
```

### 4. Launch the app

```bash
streamlit run app/streamlit_app.py
```

## Model Details

- **Algorithm:** Random Forest Classifier (scikit-learn)
- **Features:** ATP Rank, ATP Points, Surface, Court, Series, Round, Best of, Rank difference, Points difference
- **Train / Val / Hold-out split:** time-based — train < 2019, val = 2019, hold-out ≥ 2020
- **Excluded:** Betting odds (Odd_1, Odd_2), player names, match score — no leakage
- **Target accuracy:** ~65–72% (without odds, this is the realistic ceiling for ranking-based models)
